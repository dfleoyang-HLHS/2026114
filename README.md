# 教室座位表產生器｜Classroom Seating Chart Generator

一個可拖放交換座位、匯出 Excel/PDF 的網頁版教室座位表工具。

## 功能特色

- 🪑 **可調整座位配置**：支援每排 5、6、7、8 個座位
- 🖱️ **直覺拖放交換**：座位之間直接拖曳即可交換
- 📊 **自動填滿**：依人數自動排列，支援逐排、逐欄、依座號排序
- 📥 **匯出多種格式**：Excel (.xlsx)、PDF
- 💾 **本機儲存**：自動儲存到瀏覽器，重新開啟仍可使用
- 🌐 **純前端運作**：無需伺服器，瀏覽器即可使用
- 📱 **響應式設計**：支援桌面與平板裝置

## 使用說明

### 上傳點名表

1. 點選「上傳點名表」
2. 選擇 `.xlsx`、`.xls` 或 `.csv` 檔案
3. 系統自動辨識欄位：學號、班級、座號、姓名

### 調整座位

- **每排座位數**：選擇 5、6、7、8
- **排列方式**：
  - 由前到後、逐排填入
  - 由左到右、逐欄填入
  - 依班級與座號排序
- **自動填滿**：一鍵依設定排列
- **拖放調整**：
  - 座位之間直接拖曳交換
  - 清除座位重新排列

### 匯出資料

- **下載 Excel**：包含座位、班級、座號、姓名、學號
- **下載 PDF**：座位表視覺化圖档
- **儲存本機**：儲存到瀏覽器，重新開啟自動載入
- **列印**：使用瀏覽器列印功能

## JSON 資料格式

```json
{
  "students": [
    {
      "no": 1,
      "id": "310273",
      "className": "301",
      "number": "03",
      "name": "余賽亞"
    }
  ],
  "order": [1, 2, 3, null, 5, 6],
  "cols": 6
}
```

- `students`: 學生清單
- `order`: 座位順序（null 表示空位）
- `cols`: 每排座位數

## 技術堆疊

- **HTML5** + **CSS3**（響應式設計）
- **Vanilla JavaScript**（無框架依賴）
- [SheetJS / xlsx](https://sheetjs.com/) - Excel 匯出
- [jsPDF](https://parall.ax/products/jspdf) - PDF 產生
- [html2canvas](https://html2canvas.hertzen.com/) - 畫面擷取
- **LocalStorage** - 本機儲存

## 隱私與安全

- 所有資料處理均在瀏覽器本機完成
- 學生資料不儲存到伺服器
- 僅使用 LocalStorage 儲存設定
- 每台設備需分別設定

## 常見問題

### Q: 拖放沒反應？
A: 請確認使用現代瀏覽器（Chrome、Edge、Firefox），並確保已上傳點名表。

### Q: 資料會同步到多台設備嗎？
A: 不會，資料只儲存在本機瀏覽器。如需在多台設備使用，請分別上傳點名表。

### Q: 如何清除資料？
A: 點選「清除」按鈕，或清除瀏覽器資料。
