# 教室座位表產生器

## 📋 專案說明

這是一個功能完整的教室座位表產生器，支援從 Excel 點名表匯入學生資料、自動排列座位、拖放調整、以及與 GitHub 整合儲存和分享座位表。

## ✨ 主要功能

### 1. 學生資料匯入
- 📊 支援 Excel (.xlsx, .xls) 和 CSV 格式
- 📋 自動識別學號、班級、座號、姓名欄位
- 🔢 自動生成座號

### 2. 座位排列
- 🎯 自動填滿座位
- 📐 自訂每列座位數（5-8 個）
- 🔄 三種排列方式：
  - 由前到後
  - 由左到右
  - 依座號排序

### 3. 座位調整
- 🖱️ 桌面版：拖放交換座位
- 📱 手機版：長按後拖曳交換
- 🎨 視覺回饋：
  - 拖曳時卡片顏色淡化
  - 目標格子紅色框線提示

### 4. GitHub 整合
- ☁️ 從 GitHub 載入已存在的座位表
- 📤 上傳座位表到 GitHub 儲存庫
- 📋 自動列出儲存庫中的所有 JSON 檔案
- ✅ 選擇檔案視覺提示（綠色高亮）

### 5. 儲存與輸出
- 💾 儲存到本機瀏覽器（localStorage）
- 📊 匯出 Excel 檔案
- 🖨️ 列印 / 另存為 PDF
- 🗑️ 清除所有座位

## 🎯 使用流程

### 情況一：從頭開始建立座位表

1. **上傳點名表**
   - 點選「上傳點名表」按鈕
   - 選擇 Excel 或 CSV 檔案
   - 系統自動識別欄位並載入學生資料

2. **設定座位配置**
   - 選擇每列座位數（橫向）
   - 選擇排列方式
   - 輸入標題（例如：教室座位表）

3. **自動填滿**
   - 點選「✨ 自動填滿」按鈕
   - 系統自動排列所有學生

4. **調整座位**
   - 桌面版：直接拖放座位交換
   - 手機版：長按座位後拖曳到目標位置

5. **儲存與輸出**
   - 💾 儲存至本機（瀏覽器）
   - ☁️ 上傳到 GitHub
   - 🖨️ 列印 PDF
   - 📊 輸出 Excel

### 情況二：從 GitHub 載入已存在的座位表

1. **設定 GitHub 連線**
   - 輸入使用者名稱
   - 輸入儲存庫名稱
   - 輸入 Token（必要）
   - 選擇分支（預設：main）

2. **列出檔案**
   - 點選「📋 重新整理檔案」按鈕
   - 系統自動列出所有 JSON 檔案

3. **選擇檔案**
   - 從檔案列表中點選要載入的檔案
   - 看到綠色提示框「✅ 已選擇：xxx.json」

4. **載入座位表**
   - 點選「📥 載入選擇的檔案」按鈕
   - 座位表自動載入並顯示

5. **編輯與輸出**
   - 調整座位
   - 儲存或輸出

## 🔧 GitHub Token 設定

### 取得 Token 步驟

1. 前往 GitHub Settings → Developer settings
2. 選擇 Personal access tokens → Tokens (classic)
3. 點選 Generate new token (classic)
4. 設定權限：
   - ✅ `repo`（完整儲存庫權限）
5. 複製 Token 並儲存（只顯示一次）

### Token 使用

- 輸入 Token 後才能列出和載入 GitHub 檔案
- Token 會保留在輸入框中（重新整理後需重新輸入）
- 建議使用個人儲存庫避免 Token 外洩

## 📁 檔案格式

### 上傳的點名表格式

Excel 或 CSV 檔案需包含以下欄位（欄位名稱可部分匹配）：
- 學號
- 班級
- 座號
- 姓名

### GitHub 儲存的 JSON 格式

```json
{
  "students": [
    {
      "no": 1,
      "id": "110123456",
      "className": "忠孝",
      "number": "01",
      "name": "王小明"
    }
  ],
  "order": [1, 2, 3, null, 5],
  "cols": 6,
  "title": "教室座位表"
}
```

## 📱 手機版操作

### 拖放座位

1. **長按**座位（約 0.5 秒）
2. 座位卡片顏色淡化
3. **拖曳**到目標座位
4. **放開**即可交換

### 視覺回饋

- 長按時：卡片透明度降低、背景變灰、稍微縮小
- 移至目標：紅色框線、淡紅背景、稍微放大、紅色光暈

## 🖨️ 列印設定

1. 點選「🖨️ 列印 PDF」按鈕
2. 在列印對話框中選擇「另存為 PDF」
3. 調整邊界和縮放
4. 儲存 PDF 檔案

## 💡 使用技巧

1. **快速載入**：如果已有 GitHub 檔案，先載入再修改
2. **定期儲存**：調整座位後立即儲存到本機或 GitHub
3. **備份習慣**：重要座位表建議同時儲存本機和 GitHub
4. **Token 安全**：使用後清除 Token 或使用私人電腦
5. **檔案命名**：使用有意義的標題（例如：101 教室座位表）

## 🐛 常見問題

### 無法列出 GitHub 檔案

- 確認 Token 正確且有 `repo` 權限
- 確認儲存庫名稱正確
- 確認分支名稱正確（預設：main）

### 上傳 GitHub 失敗

- 確認 Token 有寫入權限
- 確認儲存庫存在且可寫入
- 確認網路連線正常

### 手機版無法拖放

- 確認使用現代瀏覽器（Chrome、Safari）
- 長按時間要足夠（約 0.5 秒）
- 確認不是空位（空位無法拖放）

### 載入 Excel 失敗

- 確認檔案格式為 .xlsx、.xls 或 .csv
- 確認包含必要欄位（學號、班級、座號、姓名）
- 確認第一列為欄位名稱
